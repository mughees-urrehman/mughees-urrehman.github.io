# mughees-urrehman.github.io

Personal academic website of Mughees Ur Rehman, served by GitHub Pages at https://mughees-urrehman.github.io.

Plain static HTML, no build step:

- `index.html` — the whole site (about, news, publications, experience, service, awards)
- `style.css` — styles (light and dark mode)
- `files/Academic_CV.pdf` — CV
- `images/` — profile photo and tab icon

Preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```
